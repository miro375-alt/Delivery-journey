# 박람회 택배 접수 — 세팅 가이드

행사 전에 아래 순서대로 진행하세요. 소요 시간: 약 30~40분 + 리허설.

---

## 1단계. 구글시트 만들기

1. [sheets.new](https://sheets.new) 로 새 시트 생성 → 이름: `박람회 택배접수 (행사명)`
2. 탭 3개 준비:

### 탭 ① `주문접수` — 시스템 전용 (직접 만들 필요 없음)
Apps Script가 첫 접수 때 헤더와 함께 자동 생성합니다. **이 탭은 절대 수정하지 마세요** (원본 보존).

자동 생성되는 컬럼:
```
A 접수번호   B 접수시각   C 영수증번호   D 주문금액구분   E 배송비결제확인
F 주문자명   G 주문자연락처   H 수령인명   I 수령인연락처   J 우편번호
K 기본주소   L 상세주소   M 배송요청사항   N 개인정보동의   O 클라이언트UUID
P 단말기   Q 중복의심
```

### 탭 ② `발송처리` — 담당자 작업용
1행에 헤더 입력:
```
접수번호 | 상태 | 제품명(매칭) | 수량 | 담당자 | 택배사 | 송장번호 | 발송일 | 비고
```
- `상태` 열: 데이터 → 데이터 확인 → 드롭다운으로 아래 값 등록
  `접수, 검수완료, 발송요청, 송장등록, 배송완료, 보류, 취소`
- 조건부 서식 권장: `발송요청`=노랑, `송장등록`=파랑, `배송완료`=초록, `보류/취소`=빨강
- 접수가 쌓이면 `주문접수` 탭의 접수번호를 이 탭으로 가져와 상태 관리
  (A2에 `={'주문접수'!A2:A}` 배열 수식으로 자동 동기화 가능)

### 탭 ③ `키오스크주문` — 제품 매칭 소스
행사 후 키오스크 정산 데이터(주문번호, 제품명, 수량, 금액)를 붙여넣는 탭.
`발송처리`의 제품명(매칭) 열에서 VLOOKUP:
```
=IFERROR(VLOOKUP(접수의영수증번호, 키오스크주문!A:C, 2, FALSE), "수동확인")
```

## 2단계. Apps Script 배포

1. 시트에서 **확장 프로그램 → Apps Script** 열기
2. 기본 코드를 지우고 `apps-script/Code.gs` 내용 전체 붙여넣기
3. 상단 설정 수정:
   - `NOTIFY_EMAILS`: 접수 알림 받을 메일 주소 (쉼표로 복수 지정 가능, 비우면 알림 꺼짐)
   - `EVENT_NAME`: 행사명
4. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나(본인 계정)**
   - 액세스 권한: **모든 사용자** ← 중요 (태블릿에서 로그인 없이 전송)
5. 권한 승인 (시트 쓰기 + 메일 발송 권한 요청됨)
6. 발급된 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`) 복사
7. 확인: 브라우저에서 그 URL을 열었을 때 `{"ok":true,...}` 가 보이면 정상

> ⚠️ 코드를 수정한 뒤에는 **배포 → 배포 관리 → 새 버전**으로 재배포해야 반영됩니다.

## 3단계. 접수 페이지 호스팅

`order.html`은 정적 파일 1개이며, **내부 서버(회사 NAS Web Station)에 올려서 운영합니다.**

### NAS 업로드 — `logis/`와 분리된 전용 폴더 사용
1. File Station(또는 SMB)으로 `cwjung` 아래에 **새 폴더 `expo`**를 만들고 `order.html` 업로드:
   ```
   www/cwjung/expo/order.html
   ```
2. 접속 URL 확인:
   - 외부/현장: `https://track.도메인/cwjung/expo/order.html`
   - 사내 LAN: `http://NAS_IP/cwjung/expo/order.html`
3. PHP·config.php 등 다른 파일은 필요 없습니다 — 이 파일 1개면 됩니다.

> `logis/` 밖의 전용 폴더라서 배송조회 시스템의 자가 업데이트(`selfupdate.php`)와
> 전혀 간섭이 없고, 행사가 끝나면 폴더째 삭제하면 정리 끝입니다.

### (권장) 자가 업데이트 — 이후 수정분을 URL 한 번으로 반영
클라우드에서 작업하는 Claude는 NAS에 직접 접근할 수 없으므로, 수정분을 NAS가 받아가게 합니다:

1. `expo/update.php`를 열어 상단 `$TOKEN = 'CHANGE-ME'`을 임의의 비밀 문자열로 변경
2. `order.html`과 함께 `www/cwjung/expo/`에 업로드 (최초 1회)
3. 이후 페이지가 수정될 때마다 브라우저에서 아래 URL만 열면 최신본 반영:
   ```
   https://track.도메인/cwjung/expo/update.php?token=<설정한 토큰>
   ```
   (GitHub에서 `order.html`만 내려받아 교체하며, 다른 파일은 건드리지 않습니다)

### 내부 서버로 돌려도 인터넷은 필요합니다
NAS는 **페이지를 서빙하는 역할**만 하고, 태블릿에서 두 가지 외부 통신은 그대로 일어납니다:
- 주소 검색: `t1.daumcdn.net` (카카오)
- 접수 저장: `script.google.com` (구글시트)

즉 **태블릿이 붙는 와이파이에 인터넷 아웃바운드가 있어야** 시트 저장이 됩니다.
잠깐 끊기는 것은 오프라인 큐가 흡수하지만, 행사장 인터넷이 아예 없다면 미리 알려주세요 —
접수 데이터를 NAS에 저장하는 PHP 백엔드 변형을 만들어야 합니다.

> 참고: LAN에서 http로 서빙해도 전 기능이 동작합니다 (http 페이지 → https Apps Script 호출은 브라우저가 허용).

## 4단계. 아이패드 세팅

1. **Safari에서 접수 페이지 접속** → 공유 버튼 → **홈 화면에 추가** (전체화면 실행됨)
2. **설정 → 디스플레이 및 밝기 → 자동 잠금 → 안 함**
3. **사용법 유도(Guided Access) 켜기** — 다른 앱 이탈 방지:
   - 설정 → 손쉬운 사용 → 사용법 유도 → 켬 + 암호 설정
   - 홈 화면 아이콘으로 접수 페이지 실행 → **전원(또는 홈) 버튼 3번 클릭** → 시작
   - 종료: 다시 3번 클릭 + 암호
4. **스태프 화면 열기**: 좌측 상단 "📦 택배 접수" 로고를 **5초간 길게 누름**
5. 스태프 화면에서:
   - **웹앱 URL**: 2단계에서 복사한 URL 붙여넣기
   - **단말기 코드**: 태블릿 1대면 `T1`, 2대째는 `T2` (접수번호 충돌 방지)
   - **설정 저장** → **🧪 연결 테스트** → "연결 성공" 확인 + 시트에 테스트 행 확인 (확인 후 행 삭제)
6. 충전기 상시 연결

## 5단계. 행사 전 리허설 체크리스트

- [ ] 실전과 동일하게 접수 3건 입력 → 시트 적재 + 접수번호 형식(`E0912-T1-001`) 확인
- [ ] 알림 메일 수신 확인
- [ ] 같은 영수증 번호로 2번 접수 → 시트 Q열 `중복의심` 표시 확인
- [ ] **와이파이 끔 → 접수 1건** (완료 화면 정상 표시 + 상단 "미전송 1건" 배지 확인)
      → **와이파이 켬** → 30초 내 자동 전송 + 배지 사라짐 확인
- [ ] 스태프 화면 CSV 백업 다운로드 확인
- [ ] 테스트 데이터 정리: 시트 테스트 행 삭제 + 스태프 화면 "로컬 백업 데이터 전체 삭제"
- [ ] 스태프 교육:
  - 접수 완료 화면의 **접수번호를 영수증에 기재**, 교환증 회수
  - **3만원 미만 건은 배송비 수취 후 확인 체크**를 스태프가 직접
  - 상단에 "미전송 N건" 배지가 계속 떠 있으면 와이파이 확인
  - 스태프 화면 진입법(로고 5초)과 Guided Access 해제 암호 공유

## 행사 후

1. 미전송 큐 0건 확인 (스태프 화면) — 남아 있으면 재전송 또는 CSV로 회수
2. `키오스크주문` 탭에 정산 데이터 붙여넣기 → 제품 매칭
3. `발송처리` 탭에서 검수 → 발송요청 → 송장등록 진행
4. 배송 완료 후: 스태프 화면 로컬 데이터 삭제 + 시트 개인정보 파기 일정 준수 (3개월 이내)
