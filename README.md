# StoreFlow — 배송여정 · 배송조회 · 제품 소개 시스템

운송장 번호로 배송 여정을 시각적으로 확인하고, 주문한 제품 소개·리뷰·추천 상품까지 한 화면에서 보여주는 데모입니다.
(`track.storej.co.kr` 형태의 배송 추적 페이지를 참고하여 제작)

## 주요 기능

- **배송조회**: 운송장 번호 입력 → 실시간 상태 조회 (목업 데이터 기반)
- **배송여정**: 주문접수 → 상품준비 → 집화 → 간선이동 → 배송중 → 배송완료 단계별 진행도 시각화
- **상세 배송 현황**: 시간순 추적 타임라인
- **제품 소개**: 이미지·설명·가격, 구매/장바구니 CTA, 고객 리뷰·평점, 추천 상품

## 실행 방법

별도 빌드가 필요 없습니다. `index.html`을 브라우저에서 열면 됩니다.

```bash
# 로컬 서버로 띄우기 (선택)
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

### 예시 운송장 번호

| 번호 | 상태 | 제품 |
|------|------|------|
| `519719884106` | 배송중 | 유기농 콜드프레스 주스 세트 |
| `884201337755` | 배송완료 | 무선 아로마 디퓨저 세트 |

URL로 바로 조회: `index.html?no=519719884106`

## 파일 구조

```
.
├── index.html      # 마크업 / 화면 구조
├── css/styles.css  # 스타일 (반응형 포함)
└── js/
    ├── data.js     # 목업 배송·제품 데이터  ← 실제 API 연동 시 이 파일 교체
    └── app.js      # 조회·렌더링 로직
```

## 실제 택배사 API 연동하기

현재는 `js/data.js`의 `TRACKING_DB`를 사용하는 목업입니다.
실제 연동 시 `js/app.js`의 `track()` 안에서 `TRACKING_DB[no]` 대신
스마트택배(굿스플로) 등의 조회 API를 `fetch`로 호출하도록 바꾸면 됩니다.
(API 키가 필요한 경우 CORS 때문에 별도 백엔드/서버리스 함수 경유 권장)
